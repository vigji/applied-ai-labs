# Applied AI — labs

Notebooks and test files for the labs of the Applied AI course, meant to be opened in Google Colab.

| Day | Lab | Open |
|---|---|---|
| 0 | MLflow: from a notebook run to a served model | [Open in Colab](https://colab.research.google.com/github/vigji/applied-ai-labs/blob/main/day-0/mlflow/mlflow-lab.ipynb) |

Each lab folder holds the student notebook and a `*_tests.py` file that the notebook downloads
from this repository. Solutions are folded inside the notebook, under each exercise.
